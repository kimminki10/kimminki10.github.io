Rememberme (기프티콘 알람 서비스) 개발기

2월 23, 2025
3 분 정도

소개

Rememberme는 알람 서비스이다. 핸드폰 속에 스크린샷 형태로 정보를 저장해두는 경우가 많은데 사용 기한이 있는 쿠폰 형태의 경우 사용하지 못하고 지나가버리는 경우가 종종 있어서 이를 잊지않고 사용할 수 있도록 알람을 해주는 서비스를 만들었다.

쿠폰이 ‘나를 기억해줘’ 라는 서비스이다.

팀원

팀원은 총 8명이었고 나는 홀로 백엔드 개발 담당을 맡았다.

기술

백엔드는 python, FastAPI를 사용해서 개발해 보기로 했다. LangChain 같은 AI 프레임워크들이 FastAPI와 연계가 좋아서 공부해보고 싶은 욕구가 있었고 AI경험이 있는 분이 있었는데 그분은 FastAPI를 공부하고자하는 욕구가 있다고 해서 FastAPI로 하기로 했는데 일을 나누다보니 혼자 하게 되었다.

스택

  • Python3.12
  • FastAPI
  • MySQL
  • Azure Blob Storage
  • Azure Web App
  • Github Actions
  • Azure OpenAI API
  • Firebase Cloud Messaging

개발기

1달동안 개발하는 프로젝트였는데 설날 주간이 끼어있었고 그 주동안에는 프로젝트를 진행하지 않기로 했다. 나는 설날에 FastAPI 공부를 하기로 했다.

FastAPI 공부

공식 홈페이지

FastAPI를 사용해서 서비스를 만들어 본적이 없어서 공부를 해야겠다고 생각했다. FastAPI 공식 홈페이지 tutorial을 따라서 공부했다. https://fastapi.tiangolo.com/tutorial/

책

그 다음 아래 FastAPI로 배우는 백엔드 프로그래밍 with 클린 아키텍처를 읽고 공부를 시작했다. DI를 중심으로 클린 아키텍처를 이해하고 FastAPI를 사용하는 방법을 배웠다.

출처: https://jpub.tistory.com/468775 [제이펍의 참 똑똑한 2비트 책 이야기:티스토리]

CI/CD 설정

Github Action 을 사용해서 CI/CD를 구성했다. 배포는 Azure Web App을 사용했다. github 랑 azure 모두 MS의 서비스여서 그런지 아주 쉽게 연결할 수 있었다. Backend 개발한 내용을 바로바로 반영해서 Frontend 개발을 하고싶다고 했기 때문에 CI/CD부터 설정했다.

주요 기능 및 모델 CRUD API 구현

주요기능은 다음과 같았다.

  1. 주요기능은 스크린샷에서 정보를 추출하는 기능
  2. 추출한 정보에서 알림을 주는 기능

유저, 알림, 스크린샷 모델을 만들었다. 각 모델의 CRUD API를 구현하고 Swagger로 문서를 공유했다. 코드에 주석만 달면 추가적인 설정 없이 Swagger 문서가 만들어진다는 것이 좋았다.

테스트 코드 작성

개발을 계속해서 진행하다보니 수정사항이 있을때 기존의 구현된 내용에 어떤 영향을 미칠지 알 수 없는 상황이 발생했다. 그래서 수정을 하고 나서 모든 API를 테스트 해봐야하는데 API가 많아지니까 테스트하지 않고 넘어가는 상황이 많았다. 결국 사이드이펙트가 빵빵 터졌고 테스트코드를 작성해야할 필요성을 느꼈다. 이 이후에 터지는 문제들은 테스트코드를 작성해서 다시 발생하지 않게 했다.

테스트 코드를 작성할 때 테스트용 데이터를 사용하기위해서 디비를 새로 만들었다. 테스트를 시작할 때 테이블을 전부 drop 하고 다시 만들어서 테스트 데이터가 항상 동일할 수 있게 했다.

FCM - Firebase Cloud Messaging 설정

처음으로 FCM을 사용해봐서 사용하는 방법에 대한 학습이 필요했다. FCM 테스트용 클라이언트를 작게 만들어보고 서버에서 알림을 보내보는 식으로 테스트를 해봤다.

음성 검색 기능

사용자가 음성으로 자신의 스크린샷을 찾을 수 있는 기능을 구현했다. 사용자 음성을 Azure Cognitive Service를 사용해서 텍스트화하고 입력받은 텍스트를 LLM을 사용해서 키워드로 분리했다. 그 후에 해당 키워드를 검색하여 스크린샷을 찾아서 반환하는 기능을 구현했다.

후기

한 달 동안 개발을 해서 짧다면 짧고 길다면 긴 시간동안 개발을 했다. 마지막에는 시간에 쫒겨서 기능만 돌아가게 어떻게든 구현해서 아쉬움이 있다. 그리고 FastAPI를 처음 사용해봤는데 아주 직관적이고 러닝커브가 짧은 것이 장점으로 느껴졌다. 다음번에는 더 좋은 구조로 개발 할 수 있을 것 같다.
