def solve(N, M, K):
    if N == M:
        return [-1]
    diff = N-M
    answer = list(range(1, N+1))
    right = answer[-diff:]
    right.reverse()
    left = answer[:-diff]
    answer = left[:K-1] + right + left[K-1:]
    return answer

inputs = map(int, input().split())
print(*solve(*inputs))

아이디어를 생각해내야하는 문제인가 싶다. N이 3십만이어서 O(n) 으로 풀 수 있는 경우를 생각해야했다. 여러 인풋을 기반으로 답을 추론하며 가장 간단한 방법을 생각해봤을 때 아래와 같은 방식으로 답을 만들어냈다.
